      Como ler os QR Codes

      Os códigos impressos seguem o formato DQR|v1|P01. O aplicativo usa o identificador para encontrar a carta. Nesta versão, as pistas são exemplos demonstrativos.

      Para multiplayer real, será necessário configurar o backend e transferir a solução secreta para o servidor. Veja o arquivo README incluído no pacote.
